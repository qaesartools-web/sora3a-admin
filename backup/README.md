# 🔐 سرعة — النسخ الاحتياطية

> ⚠️ مستودع النسخ لازم يكون **خاص** — بيه أرقام وعناوين الزبائن. لا تخليه عام أبداً.
>
> هذا المجلد (`sora3a-admin/backup`) نسخة من **الكود بس** حتى ينحفظ — مستودع `sora3a-admin` عام، فالبيانات ما تنحط هنا أبداً. الكود ينرفع لمستودع خاص اسمه `sora3a-backup`، وهناك تشتغل النسخة الليلية وتنحفظ البيانات.

كل ليلة (12:30 بعد نص الليل بتوقيت بغداد) GitHub ياخذ نسخة من بيانات Firebase ويحفظها هنا:

| المجلد | شنو بيه | متى |
|---|---|---|
| `data/daily/` | طلبات أمس + الورديات والمصروفات وطلبات المنيو وسجل العمليات لأمس | كل ليلة |
| `data/core/` | المطاعم، الحسابات، المنيو، الإعدادات، الزبائن، الكباتن، الكاشيرية، الأجهزة المعتمدة… | كل جمعة |
| `data/orders/` | كل الطلبات من أول يوم (ملف لكل شهر) | مرة وحدة (النسخة الكاملة) |

الصور (صور المنيو وإثبات التسليم) ما تنحفظ هنا لأن حجمها كبير.

## التشغيل (مرة وحدة)

1. **أضف مفتاح Firebase كسر** (نفس المفتاح اللي بـ Cloudflare — لا تلصقه بأي چات):
   المستودع ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**
   - الاسم: `FIREBASE_SERVICE_ACCOUNT`
   - القيمة: محتوى ملف المفتاح (JSON) كامل.
   - إذا ما عندك الملف: Firebase ← ⚙️ Project settings ← **Service accounts** ← **Generate new private key**.
2. **أول نسخة كاملة:** تبويب **Actions** ← «نسخة احتياطية ليلية» ← **Run workflow** ← فعّل «نسخة كاملة» ← **Run**.
3. بعدها تشتغل وحدها كل ليلة. تشوف نتيجة كل ليلة بتبويب **Actions** (✅ أو ❌).

## الاسترجاع (إذا انحذف شي بالغلط)

تبويب **Actions** ← «استرجاع من نسخة احتياطية» ← **Run workflow**:

- **file:** مسار الملف، مثلاً `data/daily/2026-10-09.json.gz` (طلبات يوم 9) أو `data/core/2026-10-10.json.gz` (المطاعم والمنيو…).
- **only (اختياري):** بس مجموعة وحدة، مثلاً `orders` أو `restaurants/<رقم المطعم>/menu`.
- **mode:**
  - `dry` — **تجربة بس**: يعرض شكد مستند راح يرجع، وما يكتب شي. ابدأ بيها دائماً.
  - `missing` — يرجّع **المحذوف بس**، وما يمس أي شي موجود (الأسلم).
  - `overwrite` — يرجّع نسخة الملف فوق الموجود (أي تعديل صار بعد النسخة يروح). استخدمه بس إذا البيانات تخربت مو انحذفت.

## الكلفة

- GitHub: المستودعات الخاصة إلها 2000 دقيقة مجانية بالشهر، والنسخة تاخذ دقيقة لو دقيقتين بالليلة.
- Firebase: كل نسخة تقرا طلبات يوم واحد (والجمعة باقي البيانات) — ضمن المجاني للحجم الحالي.

## للمطوّر

```bash
# تجربة على المحاكي
FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 PROJECT_ID=demo node scripts/backup.mjs --out=/tmp/bk --full
FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 PROJECT_ID=demo node scripts/restore.mjs /tmp/bk/daily/<يوم>.json.gz --mode=missing
```
