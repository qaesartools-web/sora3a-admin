# دليل تفعيل نظام الحماية والإشعارات — منظومة سرعة

> التطبيقات الجديدة متوافقة مع الحسابات الحالية، فلا أحد ينقطع عن الدخول بعد الدمج.
> نفّذ الخطوة 2 ثم 3 بنفس اليوم حتى تتفعّل الحماية الكاملة.

## الخطوة 1 — دمج التحديثات (GitHub)

ادمج فرع `claude/stoic-einstein-xmxbri` في `main` في المستودعات الثلاثة:

1. `sora3a-admin` (لوحة الإدارة + ملفات الحماية)
2. `sora3a-rest2` (المطعم / الكاشير)
3. `sora3a-captain` (الكابتن + صفحة التتبع)

انتظر دقيقتين حتى تتحدث صفحات GitHub Pages.

## الخطوة 2 — ربط الحسابات القديمة (من لوحة الإدارة)

1. افتح لوحة الإدارة وادخل بحساب المدير.
2. اذهب لتبويب **🛡️ الأمان**.
3. اضغط **🔍 فحص** ← ثم **✅ تطبيق الإصلاحات**.
4. راجع قائمة **حسابات الإدارة العليا**: أي حساب لا تعرفه اضغط **⛔ إيقاف**.
5. إذا ظهرت ملاحظات "تحتاج مراجعة" (مثلاً مطعم بدون حساب دخول) عالجها أولاً.

## الخطوة 3 — نشر قواعد الحماية (من المتصفح، بدون برامج)

1. افتح https://console.firebase.google.com واختر مشروع **sora3a-system**.
2. من القائمة: **Firestore Database** ← تبويب **Rules**.
3. احذف كل النص الموجود، والصق محتوى الملف `firebase/firestore.rules` بالكامل.
4. اضغط **Publish**.

✅ من هذه اللحظة: لا أحد يستطيع منح نفسه صلاحيات، ولا مطعم يرى بيانات مطعم آخر،
ولا زائر يرى هواتف أو عناوين الزبائن.

> إذا واجه أي حساب مشكلة دخول بعد النشر: ارجع لتبويب الأمان واضغط "فحص" — سيخبرك بالسبب.

## الخطوة 4 — الإشعارات والتطبيق مغلق (يحتاج خطة Blaze)

الإشعارات **داخل التطبيق** وعندما يكون **بالخلفية** تعمل الآن بدون أي شيء إضافي.
لكي تصل الإشعارات للكابتن **حتى والتطبيق مغلق تماماً** يلزم "سيرفر" صغير من Firebase:

1. في Firebase Console: الإعدادات ⚙️ ← **Usage and billing** ← **Modify plan** ← اختر **Blaze** واربط بطاقة.
   (بحجم الاستخدام الحالي غالباً لا توجد تكلفة، ويمكنك وضع حد أقصى للميزانية.)
2. على أي كمبيوتر فيه Node.js، نفّذ الأوامر التالية مرة واحدة:

```bash
npm install -g firebase-tools
firebase login
git clone https://github.com/qaesartools-web/sora3a-admin
cd sora3a-admin/firebase/functions && npm install && cd ..
firebase deploy --only functions
```

بعدها: كل طلب جديد يصل للكابتن كإشعار مع صوت واهتزاز، والمطعم يصله إشعار عند رفض الكابتن أو عند التسليم.

## ماذا يحتاج الكابتن أن يفعل؟

- يفتح التطبيق ويسجل الدخول ← تظهر له نافذة **"فعّل الإشعارات"** ← يضغط **تفعيل** ← **سماح**.
- **آيفون:** يجب أولاً إضافة التطبيق للشاشة الرئيسية (مشاركة ← إضافة إلى الشاشة الرئيسية) وفتحه من هناك.
- **أندرويد:** يُفضّل تثبيت التطبيق من زر "📲 تثبيت التطبيق".

## اختبار القواعد (للمطورين)
